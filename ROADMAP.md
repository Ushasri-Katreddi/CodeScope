# Roadmap

1. Bootstrap instructions, learning records and reproducible environment evidence.
2. Research OpenCode identity, license, pinned commit, structure and entry points. Trace other subsystems in separate approved increments with source links and labeled diagrams.
3. Review architecture and initialize project tooling step by step. Inspect the intended remote before choosing local Git initialization or clone.
4. Build Python repository discovery, parsing, indexing and retrieval. Measure simple baselines before extending ranking.
5. Verify bounded orchestration with mocks. Evaluate free inference and add scoped permissions, reviewable diffs and test evidence as approved.
6. Build a standalone interface after backend validation, publish reproducible evaluation, then consider editor and GitHub integrations.

Each step requires approval, verification, documentation and a learning checkpoint. [Implementation index](docs/03-implementation/README.md)
