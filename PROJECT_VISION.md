# Project vision

Help developers locate relevant files and symbols in small authorized Python repositories and review scoped changes with test and execution evidence. Build an engineering record that teaches how each mechanism works.

The proposed application runs independently of the editor. Start with a local CLI and add a browser interface for retrieved context, diffs and verification when the backend is ready. VS Code is the development editor. An optional later extension could use the same backend.

Begin with deterministic repository discovery, Python parsing and measured retrieval. Introduce mock model providers before measuring free inference, then add bounded task execution and reviewable changes as approved. Study OpenCode at a pinned commit and design CodeScope independently.
